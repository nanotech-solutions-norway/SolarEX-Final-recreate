Reference contexts

Three project evidence routes.

Scandinavian Quartz controlled test

High-latitude Northern Europe; Quartz passive SiO₂ pathway; coated-versus-uncoated comparison. The source context records approximately 10% output advantage for treated modules versus comparators.

  • Evidence type: controlled comparison.
  • Primary relevance: low-UV / high-latitude pathway positioning.
  • Product route: SolarEX Quartz.

Titan PV³ rooftop study

UV-sufficient rooftop environment; Titan active TiO₂ pathway; 63 coated modules monitored across 360 days with 15-minute interval data. Average uplift: +5.15%.

  • Evidence type: monitored expert study.
  • Primary relevance: active TiO₂ study context.
  • Product route: SolarEX Titan.

Middle East cleanliness reference

High-dust, high-irradiance, water-scarce context; Quartz passive SiO₂ easy-clean pathway; visible post-rain cleanliness improvement in source context.

  • Evidence type: field observation.
  • Primary relevance: high-dust O&M burden.
  • Product route: SolarEX Quartz.

Pilot framework

Recommended pilot measurement framework.

A SolarEX pilot should make the source evidence relevant to a specific site. The goal is to create a defensible treated-versus-control comparison.

Baseline yield

Collect pre-coating yield data for all modules or strings, preferably irradiance-normalized, with minimum baseline before application.

Cleaning frequency and water use

Document cleaning events, water volumes, labor inputs and visible soiling conditions for coated and control sections.

Contamination profile

Characterize soiling type, deposition rate, organic/mineral ratio and seasonal variation to validate pathway suitability.

UV availability

On-site irradiance and UV context are critical for validating Quartz versus Titan pathway selection.

Coated vs control design

Matched module pairs or strings should use equivalent module type, age, orientation, tilt and exposure.

Monitoring interval and duration

15-minute data intervals are preferred. Minimum 90 days can support review; 360 days is stronger for seasonal representativeness.

Validation workflow

From project reference to site decision.

1

Map source evidence to site context

Compare local UV availability, contamination profile, climate, cleaning method and commercial objective with SolarEX evidence contexts.

2

Select the provisional pathway

Use Quartz where passive SiO₂ adhesion reduction fits; use Titan where UV-supported TiO₂ photocatalysis fits.

3

Define treated and control areas

Design the pilot around comparable module strings, identical cleaning logs and consistent monitoring intervals.

4

Translate results into commercial action

Convert yield, cleaning and O&M data into project-specific ROI, scale-up recommendation or further review.
