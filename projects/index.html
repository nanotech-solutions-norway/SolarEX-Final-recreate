Evidence and pilot review

Projects — Contextualized Evidence for SolarEX Coatings

SolarEX project references are presented as engineering evidence: controlled comparisons, study-specific rooftop data, model-based commercial scenarios and qualitative field observations. Each reference must be interpreted within its operating context.

Evidence discipline

Proof must match the site context.

Outcomes depend on climate zone, contamination profile, UV availability, cleaning regime, module type and age, application quality, monitoring method and monitoring duration.

Context-dependent performance

Yield uplift, cleanliness improvement and cleaning burden reduction are functions of site-specific variables. Reference results support product selection for comparable site profiles.

Evidence-type transparency

SolarEX categorizes evidence as controlled comparison, expert study, qualitative field observation or financial model, avoiding unsupported generalization.

Pilot-before-scale logic

Reference evidence supports pathway selection and pilot design before large-scale coating procurement or deployment.

Reference contexts

Three project reference contexts.

Scandinavian Quartz controlled test

High-latitude Northern Europe; Quartz passive SiO₂ pathway; controlled coated-versus-uncoated comparison. The source context records approximately 10% output advantage for treated modules.

Titan expert rooftop study

UV-sufficient rooftop environment; Titan active TiO₂ pathway; 63 coated modules monitored over 360 days using 15-minute interval data. Average uplift: +5.15%.

Middle East cleanliness reference

High-dust, high-irradiance, water-scarce context; Quartz passive SiO₂ easy-clean pathway; visible post-rain cleanliness improvement compared with untreated modules.

Pilot framework

Recommended pilot measurement framework.

Baseline yield

Pre-coating yield data for all modules, irradiance-normalized, with a minimum 30-day baseline before application.

Cleaning frequency and water use

Document cleaning events, water volumes and labor inputs for coated and control sections.

Contamination profile

Characterize soiling type, deposition rate and seasonal variation to validate pathway suitability.

UV availability

On-site irradiance and UV context are critical for validating Quartz versus Titan pathway selection.

Coated vs control modules

Matched module pairs or strings should use equivalent manufacturer, age, orientation and tilt.

Monitoring interval and duration

15-minute data intervals are recommended. Minimum 90 days; 360 days preferred for seasonal representativeness.

Commercial models

ROI models translate evidence into commercial value.

Europe ROI model

  • Irradiance basis: 90 W/m²
  • Annual sunshine: 2,335 hours/year
  • Energy tariff: €0.289/kWh
  • Coating cost: €2.44/m²
  • Estimated payback: approximately 147 days

Titan study value context

  • Average yield uplift: +5.15%
  • String-level results: +5.62%, +5.22%, +4.62%
  • Additional revenue example: €128.94/year per coated string in study context
  • Broader extrapolation presented in source context only
