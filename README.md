# SolarEX Website Reconstruction

Static GitHub Pages reconstruction of the SolarEX website based on `SolarEX_Recreation_Extraction_Report_07-53_18-05-2026.md`.

## Source of truth

- Governing extraction report: `SolarEX_Recreation_Extraction_Report_07-53_18-05-2026.md`
- Canonical domain: `https://www.solarex.no/`
- Implementation branch: `rebuild/solarex-report-extraction-20260518-1225`

## Implementation model

- Static HTML/CSS/vanilla JavaScript generated by `sitegen.py` into `_site`.
- GitHub Pages deploys `_site` through `.github/workflows/deploy-pages.yml`.
- No backend, private keys, API tokens, server-side runtime, database, or API dependency is included.

## Core controls applied

- Public contact email is standardized as `info@solarex.no`.
- Chemical formulas are rendered as `SiO₂` and `TiO₂`.
- SolarEX Quartz is treated as the passive SiO₂, UV-independent, hydrophobic/oleophobic easy-clean route.
- SolarEX Titan is treated as the active TiO₂, UV-dependent, photocatalytic, hydrophilic/superhydrophilic route.
- The site avoids universal or guaranteed performance claims.
- SEO metadata, canonicals, Open Graph metadata, sitemap, robots directives, theme color and favicon are generated.
- Scroll reveal, count-up statistics, progress-bar animation and reduced-motion fallback are implemented in generated JavaScript.
- Deterministic SVG placeholders are generated where final approved SolarEX media or public PDF documents are unavailable.

## Local validation

Run:

```bash
python sitegen.py
```

This generates `_site` and validates that required files exist and protected wording rules are clean.

## Deployment

When merged into `main`, GitHub Actions runs `python sitegen.py`, uploads `_site`, and deploys through GitHub Pages.
