Document logic

Read the right document for the right question.

SolarEX documentation is organized into functional categories. Each category has a different role in technical evaluation, procurement review and pilot planning.

Application instructions

Procedural guidance for applying Quartz or Titan: surface preparation, coverage rates, temperature window, application method, hardening, cure and post-application handling.

Study documents

Contextualized evidence produced under defined conditions with methodology, monitoring interval, treatment/control logic and result interpretation.

Reference presentations

Regional and product decks used for partner briefings, buyer education, ROI framing, operating-context explanation and commercial review.

Pilot and evidence context

Guidance for mapping source evidence to local site conditions, contamination profile, UV availability, cleaning method and O&M economics.

Quartz package

Quartz documentation set — passive SiO₂ pathway.

Quartz documents support UV-independent surface-energy modification, easy-clean application, passive adhesion reduction and commercial ROI review.

Quartz application instructions

Primary procedural file for cleaning, decontamination, surfactant/tenside removal, clean-water rinse, alcohol-compatible final wipe, HVLP spray/wipe method and cure handling.

  • Manual consumption: 15–17 mL/m².
  • Industrial consumption: 15–20 mL/m².
  • Spray distance: 20–30 cm.
  • Movement speed: 0.2–0.3 m/sec.

Quartz Europe / Norway material

Regional positioning, high-latitude relevance, energy-price context, ROI framing and passive SiO₂ route logic for European and Nordic installations.

  • Europe model includes 2,335 sunshine hours/year.
  • Energy tariff example: €0.289/kWh.
  • Indicative payback framework: ~147 days.

Quartz Middle East material

High-dust, high-irradiance and water-scarce operating logic for Quartz easy-clean value and O&M reduction framing.

  • Source basis includes 270 kWh/m²/year.
  • Conservative uplift assumption: 2%.
  • Base-case payback reference: ~217 days.
Titan package

Titan documentation set — active TiO₂ pathway.

Titan documents support UV-dependent photocatalytic surface chemistry, organic contamination decomposition, hydrophilic rinse behavior and study interpretation.

Titan application instructions

Procedural file for clean/dry/grease-free substrate preparation, controlled wipe/polish application, secondary hardening, full cure and outdoor UV activation.

  • Coverage: approximately 10–25 mL/m².
  • Wipe/polish range: 10–15 mL/m².
  • Processing temperature: +5°C to +25°C.
  • Full outdoor effect: 24–48 hours under sunlight.

Titan product presentation

Commercial and technical positioning file for explaining TiO₂ photocatalysis, UV activation, reactive oxygen species and hydrophilic/superhydrophilic behavior.

  • Best fit: organic / biological fouling.
  • UV activation is mandatory for active function.
  • Use alongside Technology page review.

Titan PV³ study files

Study evidence file set for Titan performance context. Values are study-specific and should be used to inform pilot design rather than universal claims.

  • Average uplift: +5.15%.
  • 63 coated modules.
  • 360 monitored days.
  • 15-minute interval monitoring.

Document interpretation

Use SolarEX documents by evidence type.

Instructions describe procedure

Application files define required preparation, handling, cure and process constraints. They do not replace site-specific method statements.

Studies provide context

Study files describe measured results under defined conditions. Values should remain tied to the relevant monitoring context.

ROI files model scenarios

Commercial models translate assumptions into payback logic. Actual values require local energy price, production and O&M data.

Visual files explain mechanisms

Images, diagrams and graphs support technical communication and page-level buyer education.

Documentation workflow

How documentation supports a project review.

1

Start with pathway selection

Use Technology, Quartz and Titan documentation to determine whether the site should be reviewed as passive SiO₂, active TiO₂ or unresolved.

2

Check application feasibility

Review surface preparation, access, temperature, cleaning chemistry, coverage, cure and operational constraints.

3

Map evidence to site conditions

Use Projects and study documents to compare source contexts with local contamination, UV availability and O&M burden.

4

Define pilot package

Translate selected documents into treated/control design, baseline requirements, cleaning log and reporting outputs.
