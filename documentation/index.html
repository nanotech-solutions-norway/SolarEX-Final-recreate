Quartz package

Quartz documentation set — passive SiO₂ pathway.

Quartz documents support UV-independent surface-energy modification, easy-clean application, passive adhesion reduction and commercial ROI review.

Quartz application instructions

Primary procedural file for cleaning, decontamination, surfactant/tenside removal, clean-water rinse, alcohol-compatible final wipe, HVLP spray/wipe method and cure handling.

  • Manual consumption: 15–17 mL/m².
  • Industrial consumption: 15–20 mL/m².
  • Spray distance: 20–30 cm.
  • Movement speed: 0.2–0.3 m/sec.

Titan package

Titan documentation set — active TiO₂ pathway.

Titan documents support UV-dependent photocatalytic surface chemistry, organic contamination decomposition, hydrophilic rinse behavior and study interpretation.

Titan application instructions

Procedural file for clean/dry/grease-free substrate preparation, controlled wipe/polish application, secondary hardening, full cure and outdoor UV activation.

  • Coverage: approximately 10–25 mL/m².
  • Wipe/polish range: 10–15 mL/m².
  • Processing temperature: +5°C to +25°C.
  • Full outdoor effect: 24–48 hours under sunlight.
Request Titan instructions

Titan product presentation

Commercial and technical positioning file for explaining TiO₂ photocatalysis, UV activation, reactive oxygen species and hydrophilic/superhydrophilic behavior.

  • Best fit: organic / biological fouling.
  • UV activation is mandatory for active function.
  • Use alongside Technology page review.

Titan PV³ study files

Study evidence file set for Titan performance context. Values are study-specific and should be used to inform pilot design rather than universal claims.

  • Average uplift: +5.15%.
  • 63 coated modules.
  • 360 monitored days.
  • 15-minute interval monitoring.
