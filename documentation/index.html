Technical files

SolarEX Documentation

Technical files, studies and application references structured for engineering teams, EPC partners, O&M specialists and procurement reviewers. Documentation is organized by question, pathway and evidence type.

Document logic

Read the right document for the right question.

SolarEX documentation is organized into functional categories. Each category serves a distinct evidentiary and operational role.

Application instructions

Step-by-step procedural guidance for applying Quartz or Titan to solar module surfaces: preparation, coverage, application conditions and post-application handling.

Study documents

Contextualized evidence produced under defined conditions with documented methodology. Studies support technical evaluation for comparable applications.

Reference presentations

Regional and product-level decks used for positioning, partner briefings, ROI framing and commercial review.

Evidence context

Guidance on how each document category should be interpreted to support accurate product communication.

Quartz package

Quartz documentation set.

Quartz application instructions

Primary procedural document for surface preparation, application methodology, environmental conditions, coverage parameters and curing requirements.

Quartz regional references

Europe, Norway and Middle East reference decks addressing market context, ROI framing, regional positioning and deployment conditions.

Titan package

Titan documentation set.

Titan application instructions

Definitive on-site reference for surface preparation protocols, application sequencing, environmental thresholds, coverage rates and post-application requirements.

Titan product and study material

Commercial and technical positioning, TiO₂ mechanism detail and the core evidentiary study basis for Titan performance claims.
